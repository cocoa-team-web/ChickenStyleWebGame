# Ghost Gun — 3D Web Edition

Standalone original browser game prototype inspired by the general style of mobile arena shooters. It does not contain Chicken Gun assets or code.

## Run
Open `index.html` in a modern browser with internet access (Three.js is loaded from jsDelivr). For local hosting: `python3 -m http.server 8000` and open `http://localhost:8000`.

## Controls
WASD — move; mouse/touch drag — camera; 1/3/V — camera; F — shoot; E — pick/drop; Q — throw. Mobile joystick and buttons are included.
